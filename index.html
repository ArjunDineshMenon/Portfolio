03 / work 制作

Built, deployed, still up.

  1. 01

    Live

    Personal Portfolio on AWS S3

    A static site hosted straight out of an S3 bucket. I wrote the IAM bucket policy, opened public access on purpose rather than by accident, set a billing alarm so a mistake stays cheap, and turned on MFA before any of it. My first deploy onto production AWS.

    • AWS S3
    • IAM
    • HTML / CSS
    • Git
    Repository
  2. 02

    In progress

    Portfolio V2 · CloudFront + HTTPS

    Putting a CloudFront distribution in front of the S3 origin, so the site arrives over HTTPS from an edge near the visitor instead of one region. Full responsive rebuild alongside it. This is the piece I am on right now.

    • CloudFront
    • S3
    • HTTPS
    • DNS
  3. 03

    Team prototype · hackathon

    Cupola Furnace Waste-Heat Recovery

    A sensor-to-cloud architecture for recovering and monitoring waste heat in small foundries around Coimbatore. Our team designed the pipeline: sensors into AWS, an ML stage, then a live dashboard for the floor. It is a design and a prototype concept, not a shipped system.

    • AWS
    • Sensor pipeline
    • ML design
